Lorelum 帮助编码 Agent 在工作过程中找到相关的工程指导。请先完成[快速开始](./quickstart)，确保运行 Agent 的环境已经有 `lore` 命令和至少一个 Pack。

## 选择你的 Agent

| Agent | 推荐接入方式 |
| --- | --- |
| Codex | 安装 [Lorelum Plugin](./codex)。 |
| WorkBuddy | 安装 [Lorelum Plugin](./workbuddy)。 |
| ZCode | 安装 [Lorelum Plugin](./zcode)。 |
| Claude Code | 将 Lorelum Skill 放入项目或个人 Skills 目录。 |
| Cursor | 安装 [Lorelum Plugin](./cursor)。 |
| 其他能执行命令的 Agent | 使用宿主支持的 Skill 机制或项目指令。 |

## 安装 Skill

Claude Code 的项目级安装：

```sh
mkdir -p .claude/skills/lorelum
curl -fsSL https://raw.githubusercontent.com/lorelum/lorelum/main/skills/lorelum/SKILL.md \
  -o .claude/skills/lorelum/SKILL.md
```

Claude Code 的个人级安装使用同一文件，路径为
`~/.claude/skills/lorelum/SKILL.md`。

Cursor 请安装 [Lorelum Plugin](./cursor)，而不是文件式 Skill。

## 其他 Agent

能够执行命令的 Agent 可以调用同一套 CLI。按宿主支持的方式安装 Skill；若宿主使用项目指令，则将 Skill 的检索指导放入对应指令文件。

核心行为是：用 `lore query` 描述任务和当前判断，用 `lore get` 读取相关结果，再按适用条件应用指导。Agent 直接阅读默认 text，而不解析其排版。取回的 Practice 包含 `resource:` link 时，已安装 Skill 会说明如何用显示出的可变 current `packRoot` 解析它、按需读取 reference、复制 asset 后编辑，以及只在当前任务授权下显式运行 script。只有结果异常、需要排查或核对 protocol 细节时才使用 `--json`。完整执行约定见 [Agent 使用说明](./agents)。

## 第一次使用

启动一个新任务，告诉 Agent：

```text
请在确定这个任务的计划前，用 Lorelum 查找相关的工程指导。
```

当设计、实现、验证或恢复需要工程判断时，Agent 会使用已安装的指导。

## 会话中的已读候选

Lorelum 可以为 Agent 对话保留一份简短的已读 Practice 候选列表。`lore get` 成功、本机 Backend 已在运行，且宿主集成能将读取关联到会话时，CLI 才报告这次读取。宿主可以向命令传递会话身份，也可以使用受支持的活动窗口后备。列表由 Backend 存在 `~/.lorelum/sessions/<宿主>/<会话 ID>/practice-reads.jsonl`；重启 Backend 或删除原 worktree 不会清除记录。读取失败或无法关联会话就不记，不改变 `get` 的结果。

接入了子 Agent 启动 Hook 的宿主可以把候选 ID、标题和适用条件传给新子 Agent，由它决定是否自行 `lore get`，不会自动注入正文。列表可能不完整，只说明某个 Practice 被读过，不代表主 Agent 已采纳；它不是任务日志或权限依据。这项能力属于 Agent 集成的共用层；各宿主 Plugin 分别说明支持哪些 Hook。

支持在 shell 命令中传递会话身份的宿主共用[注入范围配置](./configuration#agent-shell-会话身份)；各宿主指南说明对应的 Hook 行为。

## 没有生效怎么办

1. 在 Agent 实际运行命令的环境中确认 `lore --version` 可用。
2. 确认 Skill 或 Plugin 已安装并启用。
3. 安装或更新 Plugin 后，启动一个新任务。
4. 如果 Lorelum 可以启动但无法检索指导，查看[故障排查](./troubleshooting)。

## 更新

文件安装的 Skill 直接用最新版 `SKILL.md` 替换即可。Codex、WorkBuddy、ZCode 和 Cursor 用户在宿主应用中更新 Plugin；具体步骤见各自的安装页。
