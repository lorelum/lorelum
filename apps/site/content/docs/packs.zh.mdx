Knowledge Pack 是一组带版本的 Practice。安装与你的工作相关的 Pack；Agent 描述任务和当前时刻时，Lorelum 会从中检索候选指导。

## 官方 Pack

生态目前还很小，Lorelum 维护三个官方 Pack：

| Pack             | 版本    | 内容                                     |
| ---------------- | ------- | ---------------------------------------- |
| `agentic-coding` | `0.3.1` | 规划、实施、验证、恢复和交付中的工程决策 |
| `pack-creator`   | `0.1.0` | Pack 的编写、审查和发布                  |
| `react-web-craft` | `0.1.0` | React Web 应用设计与性能：组件状态、异步数据流、代码加载、渲染与组合 |

```sh
lore pack install agentic-coding
lore pack install pack-creator
lore pack install react-web-craft
```

默认安装会解析 Registry 中最新发行版；只有在需要稳定复现时才指定固定版本。浏览本地安装内容：

```sh
lore pack list --details
lore pack list agentic-coding
```

第一条命令列出 Pack 元数据，第二条列出某个 Pack 中的 Practice；两者都不是整个生态的可用 Pack 目录。[官方 Pack 仓库](https://github.com/lorelum/lorelum-packs)包含源码和发布记录。更新、卸载、registry 与 Store 选项见 [Pack 命令](./reference/packs)。

## 更新或移除 Pack

使用 `lore pack update <pack-name>@<version>` 将已安装 Pack 更新到指定版本。Pack 内容保存与派生索引工作分别处理；确认新内容可检索前，检查 `data.indexSync`。

使用 `lore pack remove <pack-name>` 从所选 Store 中移除 Pack，其他已安装 Pack 仍然可用。响应字段和错误处理见 [Pack 命令](./reference/packs)。

## 社区 Pack

欢迎为熟悉的框架、基础设施、团队规范或其他领域[创建 Pack](./create-pack)。

`awesome-lorelum` 收集官方和社区 Pack。社区 Pack 由各自作者维护，安装前请查看来源、许可证和测试过的 Lorelum 版本。
