---
title: Model commands
description: Prepare, inspect, or unload the local embedding model.
---

Semantic query and index work prepare the model automatically. These commands help you wait for loading, inspect progress, or release resources.

Global options `--log-level <level>` and `--store-root <path>` are accepted; model state and cache are user-level, so `--store-root` does not select a different model.

The Backend must be running for model commands. Start it explicitly when needed:

```sh
lore backend start
lore model load
```

## load

`lore model load` downloads the fixed model if it is missing, verifies it, and waits until loading completes. It also retries a previous failed preparation. Progress goes to stderr; stdout contains the complete final text result, or the JSON envelope when `--json` is selected.

Repeated calls join the same preparation task.

## status

```sh
lore model status
```

The result reports `state`: `unloaded`, `loading`, `ready`, `unloading`, or `failed`, plus `encodingId`, `device`, `dimensions`, and `threads`. Loading results include `progress`; failed results include an embedding error code, a recovery message, and a safe `resource` object when a model or native file failed verification. The object names the logical file and check, with expected/actual size or digest when available; it does not reveal absolute paths.

Status does not start the Backend or download the model. If the Backend is stopped, it returns `backend.unavailable`.

## unload

```sh
lore model unload
```

Unload cancels preparation or releases the loaded runtime. It keeps the model cache and resumable download files.

Embedding and Backend errors exit `2`. `embedding.native-resource-invalid` calls for reinstalling the matching complete CLI package, not redownloading the model; `embedding.resource-invalid` identifies a model file that must be corrected. Inspect the returned `resource` and see [Troubleshooting](../troubleshooting) for recovery. See [Configuration](../configuration) for model paths and download settings.
