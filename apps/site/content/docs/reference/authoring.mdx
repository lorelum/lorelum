---
title: Pack authoring commands
description: Validate, format, and synchronize Pack source files.
---

These commands operate on a local Pack directory; they do not install or publish it.

```sh
lore validate <pack-root>
lore format <pack-root>
lore i18n sync <pack-root> --locale <locale> [--source-locale <locale>] [--practice <id> | --all]
```

`validate` checks Pack structure and reports canonical diagnostics plus localization state. Exit `0` means validation completed without Pack or localization problems; exit `1` means validation completed with a Pack validation failure or localization problems (default text and `--json` both retain the result); exit `2` means the invocation or source could not be processed.

`format` canonicalizes Practice Markdown and, when present, `i18n/manifest.yaml`. It returns `formattedFiles` and `manifestFormatted`; it exits `0` on success and `2` on invalid localization input.

`i18n sync` records the current canonical source digest for selected localized Practices in `i18n/manifest.yaml`; it does not translate or overwrite localized Markdown. `--locale` is required; use exactly one of `--practice <id>` or `--all`. `--all` selects only localized Practices already present for that locale. `--source-locale` is needed when creating a new manifest. The result identifies each synchronized path and its `sourceDigest`, plus the manifest path. Success exits `0`; failures exit `2`.

Use `lore describe validate`, `lore describe format`, and `lore describe i18n.sync` for complete schemas and error codes.
