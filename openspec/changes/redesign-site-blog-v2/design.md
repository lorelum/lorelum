## 设计方向

技术期刊式完整版面。高级感来自：
- 更大的留白比例与严格网格对齐；
- 标题、摘要、元数据三级层级拉开，字体仍为 Bricolage Grotesque / Manrope；
- 绿色只用于品牌舞台与焦点，不作为大面积默认背景；
- 每个边界都有理由，减少装饰性边框。

浅色与深色按 DESIGN.md 的光学配对同等设计，逐主题校验对比度。

## 索引页结构

1. 发现栏：左侧平铺分类链接（ALL 与可见分类），右侧搜索触发器；窄屏分类行横向滚动，页面不横向溢出。
2. 主稿：`stage` 圆角的品牌绿舞台，左标题、右图版；舞台外不再套卡片。
3. 摘要区：舞台下方独立排版，正文列 ≤ 76ch，壳上限 88rem。
4. 后续条目：分隔线列表，标题为唯一交互入口，hover 仅做封面轻微缩放与背景细微变色，标题无下划线。

## 文章页结构

- 左导航与右目录保留（≥1280px 双栏、1024–1279px 仅左栏、<1024px 仅正文，目录回落 `<details>`）。
- 首屏图版与索引一致，标题层级与索引同源。
- 正文列 620–675px 不变。

## 实施顺序（每步单独提交）

1. 索引主稿与列表样式；
2. 索引发现栏与搜索触发器的版式；
3. 文章页首屏与导航/目录间距；
4. 守卫测试迁移与新增；
5. 验收与证据。

## 验收标准

| 编号 | 标准 | 判定方式 |
|---|---|---|
| V1 | 索引首屏为绿色 stage 舞台，标题为视觉中心 | 桌面截图（亮/暗） |
| V2 | 双语、亮暗，375/768/1024/1440/1920 视口零横向溢出 | DOM 读数 |
| V3 | 正常文字对比 ≥ 4.5:1，大字与图形 ≥ 3:1 | 计算样式读数 |
| V4 | 交互控件 ≥ 44px，焦点环可见不裁切 | DOM 读数 + 键盘实测 |
| V5 | 关闭 JS 请求 `?category=`/`?sort=` 返回完整静态索引 | 无脚本请求 |
| V6 | 搜索弹窗空输入无结果；有效输入匹配；返回前进恢复 `q` | 浏览器实测 |
| V7 | 测试、lint、typecheck（仅两项既有错误）、build 通过 | 命令输出 |
| V8 | 守卫测试按获准迁移，无新增宽松断言 | diff 审查 |
| V9 | 回滚演练：`blog-v1-baseline` 上门禁仍全绿 | 在临时 worktree 复跑门禁 |

## 回滚演练
