## Context

用户确认以文字选择文章，而非 hover 揭示信息；本设计替换本 change 的旧主稿舞台与循环区块方案。旧实现与验收历史保留在提交 `239b6ee`，不在长期方案中继续累计相互冲突的版本段落。

观察到的入口为两套 `routes/blog/index.tsx` 与 `routes/$lang/blog/index.tsx`；服务端返回完整可见元数据与筛选 slug，索引屏将筛选后的记录交给 `model/index-layout.ts`。旧模型生成 hero/grid/band/split 循环，旧 CSS 在精细指针下隐藏主稿文字。这两处分别拥有要替换的编排规则和表现规则。正文、语言回退、草稿、搜索匹配与排序已有独立模型和行为测试，不重建第二条内容管线。

## Goals / Non-Goals

**Goals:** 标题与摘要常显；默认首页一个左文右图主推；一致的双列封面卡片；筛选与排序的结果模式；URL 分页；没有图片时仍完整可读；以简洁的主题封面替代邮票式流程图和无语义抽象图。

**Non-Goals:** 不重做文章页导航、目录与正文排版；不改变 frontmatter、检索语义、日期、主题 tokens 或部署；不新增字体、依赖、人工精选字段、订阅、轮播、无限滚动或持久状态。封面素材仍由索引与文章页共用，素材更新不等于重做文章阅读布局。

## Decisions

### 信息与布局职责

`BlogIndexScreen` 保留完整记录给发现控件，从筛选 slug 得到有序结果，并决定是否允许主推：只有 `category === undefined && q === undefined && sort === "newest"` 为真。路由传入页码；分页和主推排除由一个纯模型负责，组件不再复制列表切片或推导页数。

最小合同：

```ts
interface BlogIndexLayout {
  readonly featured: BlogIndexEntry | undefined;
  readonly posts: readonly BlogIndexEntry[];
  readonly page: number;
  readonly pageCount: number;
  readonly total: number;
}

layoutIndex(entries: readonly BlogIndexEntry[], options: {
  readonly page: number;
  readonly featureLatest: boolean;
}): BlogIndexLayout;
parseBlogPage(value: unknown): number;
```

普通页大小为 12。允许主推时始终把第一篇排除在普通分页序列之外，只在第一页返回 `featured`；因此 26 篇文章产生一篇主推和 12/12/1 个普通条目。没有结果时返回 page=1、pageCount=1、空列表。有效但过大的页码钳制到末页，不返回错误空态。索引仍返回完整记录给分类与搜索弹窗，不新增服务端分页协议或数据源。

### 页面结构

主推文字占较大一侧，封面占较小一侧，文字不覆盖图像；手机先文字后图。普通卡片为图片在上、文字在下的独立单元，桌面双列、窄屏单列。图片按原始比例铺满卡片宽度，只有外层卡片负责共享 panel 圆角裁切，不在图片上重复叠圆角、边框或固定比例底框；键盘焦点绘制在外层，不被裁切。文字区域保留一致内间距，元信息置于末尾，不裁切长摘要以齐高。没有 authored image 时直接显示文字区域，不绘制空图框。仍有文章收尾消费者的生成式封面保持原有行为。

主推与列表可独立分区，但所有真实条目必须保持列表语义和稳定唯一 key。删除旧区块判别联合、跨行配对、循环布局 CSS 与 hover 遮罩。条目标题只保留一个链接，拉伸覆盖点击区域，不增加重复的“阅读”按钮；焦点不被图像裁切容器裁掉。标题和摘要不做视觉截断。

### URL 与发现控件

两套索引路由都验证 `page`，默认 1；默认查询中间件同时移除 `sort=newest` 与 `page=1`。页码只影响纯布局，不需要成为元数据查询的 loader 依赖。分页链接保留 category/sort/q；分类、搜索应用、重置继续显式构造新查询，不传旧 page，因而回到第一页。现有的查询 Worker-first 与 query 预渲染排除保持不变，确保首次响应就能正确呈现分页结果。

分页控件只在 pageCount>1 时显示，当前页通过 aria-current=page 表示；长页码序列用首尾、当前邻页与不可交互省略号表达，不创建与总页数线性增长的 DOM。上一页/下一页边界不生成伪链接。浏览器历史由现有路由器拥有，不新增本地存储或滚动管理器。

### 封面

首发封面使用本地 SVG，以简洁的大字和三个等权条件表达同一任务、Baseline / Placebo / Oracle 与共同 Evaluation。使用中性纸面和品牌绿组织层次，不将细小流程框、连线与微型标注作为封面主体；不使用随机壁纸或虚构数值。标签解释主题而非宣称结果；正文标题与摘要不依赖图中文字。首发素材使用 16:10 比例，索引按图片自身比例完整展示，不额外创建会留下底色缝隙的固定比例容器。继续沿用公开图片路径，不新增 image 字段或外部资源。

### 兼容与替代方案

普通卡片选择独立封面在上、完整文字在下，让图片和长摘要获得各自的阅读空间；不再使用文字旁的微型缩略图。主推仍为左文右图，列表不按条目数量或序号切换视觉等级。旧 URL、语言回退、搜索语义及正文可用性不变；`page` 只改变列表可见窗口。页面直接切换，不保留新旧开关或兼容组件。

## Risks / Trade-offs

- 英文标题和真实摘要较长：允许自然换行，以 1/3/12 篇长文本夹具检查，而不是裁切文字以适配卡高。
- 新增文章会改变按日期分页的位置，这是时间排序本身的结果，不保存跨发布快照。
- 无图条目与有图条目的高度可不同；用一致对齐与分隔保持可扫读，不用空白图片强制齐高。
- SVG 与正文共用路径，必须同时检查文章页图片可读，但不顺便改正文布局。

## Verification

模型用 colocated 行为测试覆盖主推唯一性、1/3/12/13/26 条边界、完整分页无遗漏、结果模式、输入不变和非法/过大页码。路由默认参数中间件覆盖默认页移除与其他状态保留，不添加源码/CSS 拼写断言。

主线程统一执行 fmt、lint、typecheck、站点测试与构建。实际构建预览验证 1/3/12 篇与超过一页的临时内容，中英文、亮暗、375/768/1440/1920；检查静止文字可见、hover 不改变内容、整条点击与键盘、分类/搜索/翻页/返回、无脚本响应、缺图与长文本、焦点和无横溢出。临时内容只用于本地验证，不发布、不提交。
