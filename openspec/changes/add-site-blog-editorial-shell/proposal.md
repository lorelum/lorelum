## Why

维护者看过当前实现后认为博客**缺设计感**，并给出三处具体观察：索引与文章页左侧没有导航栏、文章页的目录离右边缘太远、文章页下滑时导航栏不像首页那样收缩成一个紧凑组件。

三条观察都能落到读数上（生产构建、浅色、`apps/site`）：

| 观察 | 现场读数 |
| --- | --- |
| 目录离右边缘太远 | 整块版面是固定 **976px 居中孤岛**；1440 下 TOC 轨距右边缘 **241px**，1920 下 **481px**（正文列 664px，左右各空 465px） |
| 索引页显空 | 索引的 `<main>` 只有 **664px**，用的是阅读列宽而不是版面宽度；1920 下左右各空 621 / 636px；页高 900px 且**不能滚动** |
| 导航不收缩 | 文章页滚动 600px 后只有底板 `opacity 0 → 1`，`.landing-navbar__panel` 的几何**完全不变**；首页的 morph 改变的是 panel（`width: min(50vw, 896px)`、`border-radius: 999px`、`marginTop: 0.75rem`），而这条时间线在无 hero 的路由上**根本没有被创建** |

根因是形态选择而非细节：博客用的是「居中阅读孤岛」，而同仓库的 docs 面**已经是通栏三栏编辑壳**（1440 下侧栏 0–268、内容 268–1157、目录 1157–1425，**目录距右边缘 0px**；1920 下目录距右边缘 176px）。因此本 change 的形态是**让博客用上 docs 面已经在用的那套壳**，而不是发明一套新布局——对齐的是本仓库自己的设计语言，参照物只是旁证。

本 change **引入新的产品行为**（博客的版面结构与导航的挂载态），不是记录既有行为。

## What Changes

- **新增 `site-blog-shell` capability**（或并入既有 `site-feature-architecture`，见「归属」），定义博客编辑壳的可观察合同：三栏结构、各栏在断点上的存在性、阅读列宽度上限、目录与左栏贴壳边缘、导航的挂载态。
- **三栏壳**：博客索引与文章页 MUST 渲染同一套壳——左栏（博客导航）、居中阅读列、右栏（文章页的目录；索引页无右栏）。左栏与右栏 MUST 贴壳的左右边缘，与 docs 面一致。
- **左栏内容**：本-变更-范围内 MUST 由**已发布文章**与**分类**派生（无独立数据源）：当前文章高亮、全部文章、分类列表。**n=1 时必须仍然是可用的导航**（1 条文章 + 3 个分类），而不是空壳。
- **导航挂载态**：博客路由上，导航 MUST 在滚动越过文章头部后进入与首页相同的紧凑态（复用现有 panel morph 的几何），并在回到顶部时复原；MUST NOT 依赖 hero 的存在。**docs 面 MUST NOT 受影响**。
- **图版出栏**：文章内的图与表格 MAY 使用壳宽而非阅读列宽（编辑版式的常规做法），正文仍受 68ch 度量约束。
- **阅读列宽度不变**：664px（计划 §5 的 620–675 区间与 68ch 论证）——本 change 拓宽的是**壳**，不是阅读列。

**明确不做**（越界与欠交付同为失败）：§3.6 延后项（markdown 孪生 / llms.txt / JSON-LD / hreflang / `og:image` / `series`·`canonical` / 阅读时长 / 相关阅读 / RSS）；打印样式；`packages/ui` 新增导出；五个 token 缺口；`prefers-reduced-motion`；任何「让版面看起来被设计过」的装饰（眉标、装饰点、分区编号——`DESIGN.md` 的 Don'ts 明确禁止）。

## 已确认的决定（三处**推翻记录在案的决定**，维护者 2026-09-22 确认）

1. **左侧栏**：**加**，并接受 n=1 时的稀疏——左栏由已发布文章与分类派生，结构与 n=50 时一致。这推翻了计划 §3 / 决定第 7 项的「n=1 刻意简单」与「索引不做永久筛选 chrome」。
2. **导航挂载态**：**只在博客路由启用**，docs 面维持全宽导航（同一个导航组件在博客与 docs 上行为不同，这是有意为之）。这推翻了计划 §2 的「无 hero 时 morph 跳过」。
3. **阅读列宽度**：**保持 664px**（计划 §5 的 620–675 实测与 68ch 论证、以及换行矩阵的守卫全部继续有效）；本 change 拓宽的是**壳**，不是阅读列。

## Impact

- **面**：博客索引与文章页（两语言）× 亮/暗 × 375–1920；共享导航（博客路由生效，docs/landing 不受影响）。
- **受影响的既有守卫**：`styles/blog.test.ts` 的 `--blog-*` 冻结清单（新增壳尺寸别名需同步）、52 格换行矩阵、键盘遍历与触屏可达读数、`probe=*` 性能探针。
- **不受影响**：docs 面（已满足同一壳合同）、内容契约（`site-blog-content`）、检索与 CLI。
